# 🚀 Lighthouse AI

Lighthouse AI is a web-based Artificial Intelligence application developed using **Django** and **Machine Learning** techniques. The platform provides intelligent predictions, data analysis, and insights through an interactive and user-friendly web interface.

---

## 📌 Overview

The project combines the power of Machine Learning with Django's robust web framework to create an application capable of processing user inputs, generating predictions, and presenting results in an easy-to-understand format.

This project was developed as part of academic and research work in the field of Data Science and Artificial Intelligence.

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/lighthouse-ai.git
```

### 2. Navigate to Project Directory

```bash
cd lighthouse-ai
```

### 3. Create Virtual Environment (Optional but Recommended)

```bash
python -m venv venv
```

Activate the environment:

**Windows**

```bash
venv\Scripts\activate
```

**Linux / MacOS**

```bash
source venv/bin/activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Apply Database Migrations

```bash
python manage.py migrate
```

### 6. Run the Development Server

```bash
python manage.py runserver
```

## 🚀 Usage

1. Start the Django server.
2. Open your browser and navigate to:

```text
http://127.0.0.1:8000/
```

3. Upload data or provide input values.
4. Run the prediction process.
5. View generated results, insights, and visualizations.

---

## 📊 Application Workflow

1. User enters data through the web interface.
2. Django processes the request.
3. Machine Learning model analyzes the input.
4. Predictions are generated in real time.
5. Results and visualizations are displayed to the user.
